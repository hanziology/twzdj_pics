# twzdj_pics

Pictures used in 統外字登記.xlsx.

The file 統外字登記.xlsx contains information about characters that were initially intended to be added to [zi.tools](https://zi.tools/), and it has been updated and maintained by fellow editors. Since [zi.tools](https://zi.tools/) currently has no plan to add the corresponding entries, it would be helpful to record them in another accessible place, such as [rare.glyphatlas.org](https://rare.glyphatlas.org/).
